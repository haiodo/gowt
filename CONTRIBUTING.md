# Contributing to gowt

## Build and test

Go 1.27 or newer (see `go.mod`). No C compiler, no Java.

| Command | What it does | Opens windows |
|---|---|---|
| `make check` | `vet`, `test`, `xcheck`, `examples-check`, `api-check`, `qa-check`. Run it before a pull request | no (without `GOWT_GUI_TEST`) |
| `make xcheck` | platform-neutral packages build for darwin, windows and linux and import no platform package | no |
| `make test-swt` | the translated SWT tests against `tests/expected[_<os>].txt` | yes |
| `make test-jface` | the JFace tests against `tests/expected_jface[_<os>].txt` | yes |
| `make snap-check` | ControlExample snapshots against `tests/snapshots[_<os>]` | yes |
| `make gen-check` | committed generated code equals what the generator produces | no |

The tests that open windows skip unless `GOWT_GUI_TEST=1` is set. With it, the tests in the facade, `look`, `icons`, `swt`, `webview`, `qa/qatest` and `examples/qa` open real windows on your desktop. Without a display on Linux, use `xvfb-run`.

Hosted CI builds and vets every OS and runs the Linux gates under Xvfb. The macOS and Windows window tests are not run there.

## Generated code

`swt/`, `jface/`, `browser/`, `tests/swttests/`, `tests/jfacetests/`, `examples/controlexample/` and the translated parts of `internal/` come from the Java sources of Eclipse SWT and JFace through `tooling/j2go` and `tooling/port.sh` (`make gen`). Files that start with `Code generated by j2go` are never edited by hand. To change one, change the generator, or put the code in a `*_manual*.go` file. [docs/internals.md](docs/internals.md) has the map.

- Keep the licence and copyright headers of translated files; they are part of the generated output.
- `make gen-check` regenerates all three platforms and fails if the tree differs. It needs a clean tree under the generated paths and the SWT and JFace sources at the commits in `tooling/source-pins.env` (`SWT_REPO`, `UI_REPO`). CI runs it.
- A generator change is committed together with the regenerated output.
- The Linux binding in `internal/gtk` is generated from GIR files. Do not translate SWT's `Eclipse SWT PI/gtk` (LGPL) into it.

## Licence and sign-off

gowt is EPL-2.0. A contribution is accepted under the same licence: inbound = outbound.

Contributions are made under the [Developer Certificate of Origin](https://developercertificate.org/). Sign every commit with `git commit -s`, which adds the line

```
Signed-off-by: Your Name <you@example.com>
```

using the name and email of your git config. CI fails a pull request in which a commit has no such line. To add it to commits you already made: `git rebase --signoff origin/main`, then `git push --force-with-lease`.

## Commits

One line, no full stop, naming the area and then what changed, as in `git log`:

```
ci: Node 24 actions (checkout v7, setup-go v7), pin ubuntu-24.04
QA focus on macOS: first responder of an inactive app's window, FocusIn/FocusOut follow
docs/qa.md: actions, dialogs and Eventually
```

A body is welcome when the reason is not obvious from the diff. A change to the facade API updates `tooling/apidump/facade-api.txt` (`go run ./tooling/apidump -facade -update`) and the page of [docs/](docs/index.md) that describes it.

## Bugs

Open an issue with the Bug report template: gowt version, OS and architecture (for Linux the session type, X11 or Wayland), what you did, what you saw, and the smallest program that shows it. For a look-and-feel problem, a screenshot.

## Running the checks on your machine

The tests run on one Mac, under Wine and in Docker. Results from real Windows, Linux (X11 and Wayland) and other macOS versions are useful: run `go run ./cmd/fieldcheck` and attach the zip it writes to an issue with the Field check template. See [docs/field-check.md](docs/field-check.md).
