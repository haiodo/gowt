# gowt

Native GUI for Go: Eclipse SWT translated from Java to Go. First target - macOS (cocoa).

| Path | What |
|---|---|
| `swt/` | Public API, one Go package: Java packages `org.eclipse.swt`, `graphics`, `widgets`, `layout`, `events` import each other in a cycle, Go does not allow that |
| `internal/cocoa/` | AppKit bindings, generated from SWT `*.bridgesupport` + `*.extras` |
| `internal/jrt/` | The subset of the Java runtime the translated code uses |
| `tooling/j2go/` | Java -> Go translator on Eclipse JDT |

Files `swt/*.go` with the header `Code generated by j2go` are regenerated by the translator and are not edited by hand.
Hand-written code lives in `*_manual.go`.
